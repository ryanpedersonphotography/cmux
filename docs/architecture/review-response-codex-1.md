# Response to the Codex review of PR 1

**Review:** gpt-5.6-sol, extra-high reasoning, attached as the Codex review of this PR.
**Verdict there:** reject stage 1 as written. Option B stands.
**This note:** each claim was re-read against cmux `72a39c338ef6e4d37e9ab29892f6561df1527781` and the Studio archive `35a0d1af631a53958883e61c1b98ab072195b11c` at `/tmp/agentflow-studio`.

## Errors

| # | Claim | Verdict | Evidence |
| --- | --- | --- | --- |
| 1 | `seq` and `boot_id` are both process-local, and a restart sets `resume.gap` | Agree | Only `boot_id` is process-local (`Sources/CmuxEventBus.swift:281`). `CmuxEventSequenceStore` leases durable ranges across processes (`Sources/CmuxEventSequenceStore.swift:4-8`, `18-21`, `42-57`). `publishDurableOnPublicationQueue` allocates from that store (`CmuxEventBus.swift:409-420`). `loadPersistedEvents` restores `~/.cmuxterm/events.jsonl` (`:717`) and `completeRestore` raises the high-water mark (`:575-588`). `subscribe` sets a gap when restore is in progress (`:499`), when `after` is older than the in-memory window (`:529`), when `after` is newer than this process (`:532`), or when the log has unreadable records (`:548-554`). A restart alone does not. |
| 2 | Team-run approvals were overgeneralized | Agree | Orchestrator workflows, routines, and the orchestrator team runner still cannot answer a tool: `runAgentPrompt` (`packages/orchestrator/src/agents.ts:136-143`) and `packages/orchestrator/src/teams/context.ts:141-168` use `PendingApprovals` and leave the tool unrun. Chat and room team turns are a different path. `captureMemberApprovals` (`packages/engine/src/turn.ts:399-439`) keeps one member and denies the others. `rooms.test.ts:286-305` continues that member after `approvals.respond`. The audit's sentence that team runs cannot be answered was too broad. |
| 3 | A new `PanelType` needs a special decoder arm, and the edit list was complete | Agree | `PanelType.init(from:)` accepts any current case through `Self(rawValue:)` (`Sources/Panels/Panel.swift:27-33`). The later arms are legacy aliases. Unknown raw values throw (`:82-85`). The plan omitted the workspace encode switch (`Sources/Workspace.swift:616`, agent-session arm `:794-806`), `createPanel` (`:1591-1622`, agent-session restore `:2354-2366`), and both dock switches, which drop an unsupported type with `default: return nil` (`Sources/DockSplitStore+SessionSnapshot.swift:442`, `Sources/DockSplitStore+SessionRestore.swift:256`). |
| 4 | `@libsql/client` is the native addon | Agree | `packages/db/src/index.ts:1` imports `createClient` from `@libsql/client`. `createDatabaseStore` (`:86-95`) is that JavaScript client. The standalone trace names `@libsql/darwin-arm64` (`apps/web/next.config.ts:27-33`). |
| 5 | Licensing sentences were stronger than the files | Agree | Root `LICENSE:21-22` says every directory outside the six BUSL paths stays under the license this file or the directory's own notice states. `workers/fleet-artifacts/` has no `LICENSE` file, so "unverified, do not assume GPL" overshot the file. | 6 | `next start` was treated as interchangeable with `next dev` | Agree | `apps/web/package.json:6-8`: `build` is `next build`, `start` is `next start`. The baseline ran install, typecheck, and unit tests. It did not run `next build` or `next start`. |

Upstream CI restores or downloads the framework before compile (`.github/workflows/ci-macos.yml:715-731`). The proposed job ran `test-unit.sh` and left that step out. |
| 8 | The docs contradicted the recommendation | Agree | `target-architecture.md` said option B was not selected and that the audit could not read Studio, after ADR 0001 had recommended B from the archive. `phase-1-plan-revised.md` still said Studio's event schema and supervisor behavior were unread. |

## Risks

| # | Claim | Verdict | Evidence |
| --- | --- | --- | --- |
| 1 | P0. With no desktop token, a local process can call the API. The guard test executes `/bin/sh -c id` | Partly agree | The hole is real. `desktopTokenProblem` returns null when no token is installed (`apps/web/lib/server/request-guard.ts:82-90`). `originProblem` (`:235-243`) requires `Origin` only for mutations; a missing `Origin` passes `isTrustedOrigin` (`:215-219`). Host and forwarded-header checks do not stop a process on the same machine. The disagreement is the last sentence: `request-guard.test.ts:71-76` asserts that `guardRequest` returns null for a POST body whose JSON names `/bin/sh` and `["-c", "id"]`. The test does not spawn a shell. The permitted body is still the risk. |
| 2 | P0. No WKWebView transport covers every request type, and stage 1 deferred the token | Agree | Electron's `installSession` adds `x-grokbot-desktop` on navigations, fetch, EventSource, and server actions (`apps/desktop/src/main/session.ts:10-24`). The token arrives on `process.parentPort` (`server-host.ts:21`, `56-63`) and is stored with `installDesktopToken` (`desktop-token.ts:19-20`), never in the environment (`env.ts:8`, `desktop-token.ts:1-7`). A header on the first `URLRequest` does not cover later fetches. ADR 0001 and the hosting note deferred the token. |
| 3 | P1. Runtime discovery and supervision were underspecified | Agree | Root `package.json:5-8` requires Node `>=22.15` and pnpm `12.8.1`. Finder gets launchd's environment; `login-env.ts:3-20`, `33-46`, `98-145` runs a bounded login shell and falls back. `buildServerEnv` (`env.ts:27-39`) strips `NODE_OPTIONS`, `GROKBOT_DESKTOP_TOKEN`, and `ELECTRON_` / `npm_` / `DYLD_` prefixes, then forces `HOSTNAME`, `PORT`, and `GROKBOT_DATA_DIR`. The cmux plan named none of that, and it did not name process-tree termination, log draining, or the crash limits in `restart.ts:1-13`. |
| 4 | P1. Port, health, and data-directory ownership | Agree | `choosePort` documents a bind race between probe and listen (`apps/desktop/src/main/port.ts:21-24`). `/api/health` returns `{ok, app: "grokbot", onboarded}` from settings (`apps/web/app/api/health/route.ts:4-13`) and is token-exempt (`request-guard.ts:72-74`). No data-directory owner lock was found under `apps/desktop` or `apps/web/lib`. |
| 5 | P1. Restore can load early, and an unknown panel fails the snapshot | Agree | Unknown `PanelType` throws (`Panel.swift:82-85`) inside `SessionPanelSnapshot` (`SessionPersistence.swift:1757-1792`). Schema version is 1 (`SessionPersistence.swift:17-19`). A version mismatch or a decode failure is `.unusable` (`SessionSnapshotRepository.swift:69-75`). Startup then returns the backup or history (`:461-472`). `preserveNewerSchemaSnapshot` copies a file aside only when the probed version is newer (`:275-278`). A version-1 file with an unknown type is not that case. Dock persistence drops one unsupported panel (`DockSplitStore+SessionRestore.swift:256`) instead of failing the file. |
| 6 | P1. Studio-to-cmux event transport was unnamed | Agree | `CmuxEventBus.subscribe` (`:471`) reads cmux's own bus. Studio's live stream is `GET /api/events` (`apps/web/app/api/events/route.ts:6-18`), and `eventResponse` states there is no replay buffer (`apps/web/features/events/stream.ts:26-27`). Naming `workflow.run` does not define authentication, cursors, or what a subscriber does after a gap. |
| 7 | P2. ATS does not protect the panel | Agree | `Resources/Info.plist:236-240` sets `NSAllowsArbitraryLoadsInWebContent` to true. Exact-origin cancellation, a dedicated data store, popup denial, and a minimal bridge are the controls that exist on the agent-session host (`AgentSessionWebRendererCoordinator.swift:250-298`, `370-375`). That host does not set `websiteDataStore`. |
| 8 | P2. Stage 2 needs provenance, not a declaration | Agree | The archive shows no grant and no per-package license. Stage 1's boundary, running a checkout the user already has and not copying it into this repo, matches the files. A later bundle needs ownership that this audit did not establish, a written grant, notices for dependencies and native binaries, and a corresponding-source plan. Counsel decides the combined-work question. |
